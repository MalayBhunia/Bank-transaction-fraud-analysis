# 🔍 Bank Transaction Fraud Analysis

## 📌 Project Overview

This project presents a comprehensive fraud analytics study on a large-scale banking transaction dataset containing **1 million transactions**. The objective is to identify fraud patterns, analyze financial risk factors, and generate actionable business insights using **Exploratory Data Analysis (EDA)**, **Data Visualization**, and **Statistical Analysis**.

The project focuses on understanding how customer behavior, transaction characteristics, and operational factors influence fraudulent activities within banking systems.


## 🎯 Project Objectives

* Analyze transaction behavior and fraud patterns.
* Identify key risk factors associated with fraudulent transactions.
* Compare fraudulent and legitimate transaction characteristics.
* Perform statistical testing to validate observed patterns.
* Generate business insights and recommendations for fraud prevention.


## 📊 Dataset Information

The dataset contains **1,000,000 banking transactions** collected across multiple countries and includes customer, transaction, geographic, and fraud-related attributes.

### Key Features

* Transaction Amount
* Customer Age
* Credit Score
* Payment Method
* Merchant Category
* Device Type
* Failed Authentication Attempts
* Transaction Time Gap
* International Transaction Indicator
* Fraud Status

## 🔬 Statistical Techniques Used

### Mann-Whitney U Test

Used to determine whether significant differences exist between fraudulent and legitimate transactions for:

* Transaction Amount
* Failed Attempts
* Transaction Time Gap

### Chi-Square Test of Independence

Used to evaluate relationships between fraud occurrence and categorical variables such as:

* Payment Method
* Device Type
* Merchant Category

### Correlation Analysis

Used to identify relationships among numerical variables and fraud occurrence.



## 💡 Key Findings

* Transaction amount is a significant fraud indicator.
* Failed authentication attempts show a strong association with fraud.
* International transactions exhibit higher fraud risk.
* Fraud rates vary across payment methods and merchant categories.
* Behavioral indicators are more informative than demographic characteristics.
* Customer age has limited influence on fraud occurrence.
* Statistical testing confirmed several observed fraud patterns.



## 📌 Business Recommendations

* Implement enhanced monitoring for high-value transactions.
* Apply additional verification after multiple failed authentication attempts.
* Strengthen controls for international transactions.
* Develop merchant-category-specific fraud detection rules.
* Prioritize behavioral indicators in fraud risk assessment.
